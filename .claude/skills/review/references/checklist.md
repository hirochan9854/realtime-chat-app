# Review Checklist

## 自動チェック

- [ ] TypeScript コンパイル通過（`npx tsc --noEmit`）
- [ ] Lint 通過（プロジェクトの lint ツール）
- [ ] テスト通過

## コードレビュー

### Critical（必ず確認）

- [ ] セキュリティ脆弱性がないか（XSS, SQL Injection, CSRF）
- [ ] 機密情報がハードコードされていないか（API keys, passwords, tokens）
- [ ] データ損失リスクがないか
- [ ] 型安全性が確保されているか（any, as 多用していないか）

### High

- [ ] 主要ロジックにテストがあるか
- [ ] エラーハンドリングが適切か
- [ ] アクセシビリティが考慮されているか
- [ ] アーキテクチャ規約に違反していないか（stack 層のルールに基づく）

### Medium

- [ ] コードの可読性が十分か
- [ ] 重複コードがないか（DRY）
- [ ] 命名が明確か
- [ ] 不要なコード/コメントが残っていないか

### Nit

- [ ] フォーマットが統一されているか
- [ ] import の整理

## UIデザインレビュー（UI変更時、design 層がある場合）

- [ ] 画面の主役が明確か
- [ ] 情報の優先順位にメリハリがあるか
- [ ] テンプレ的な並べ方になっていないか
- [ ] そのプロダクト固有の情報設計か
- [ ] 色に役割とルールがあるか
- [ ] 同じ色に複数の意味を持たせていないか
- [ ] 実データを入れても破綻しないか（長文/0件/異常値/重複）
- [ ] 不要な装飾を削ったか

## アーキテクチャレビュー（stack 層のルールに基づく）

- [ ] 層間の依存方向が正しいか
- [ ] ドメインモデルが純粋か（UI都合の型が混入していないか）
- [ ] Repository パターンが守られているか
