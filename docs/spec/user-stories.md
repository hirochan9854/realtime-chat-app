# User Stories

## US-001: ユーザー登録
- **As a** 新規ユーザー
- **I want to** メールアドレスとパスワードでアカウントを作成したい
- **So that** チャットアプリを使い始められる
- **Priority:** Must
- **Acceptance Criteria:**
  - [ ] メールアドレスとパスワードを入力してサインアップできる
  - [ ] ユーザー名を設定できる
  - [ ] サインアップ後、チャット画面に遷移する

---

## US-002: ログイン・ログアウト
- **As a** 既存ユーザー
- **I want to** メールアドレスとパスワードでログインしたい
- **So that** 自分のアカウントでチャットを利用できる
- **Priority:** Must
- **Acceptance Criteria:**
  - [ ] ログインフォームでメール + パスワードを入力できる
  - [ ] ログイン成功後、チャット画面に遷移する
  - [ ] ログアウトボタンで認証を解除できる
  - [ ] 未ログイン状態でチャット画面にアクセスするとログイン画面にリダイレクトされる

---

## US-003: チャンネル作成・参加
- **As a** ログイン済みユーザー
- **I want to** チャンネルを自由に作成・選択したい
- **So that** トピックごとに会話を整理できる
- **Priority:** Must
- **Acceptance Criteria:**
  - [ ] チャンネル一覧がサイドバーに表示される
  - [ ] 新しいチャンネルを名前付きで作成できる
  - [ ] チャンネルをクリックしてメッセージエリアに切り替えられる
  - [ ] 新しいチャンネルが作成された際、リアルタイムでサイドバーに反映される

---

## US-004: テキストメッセージ送信
- **As a** ログイン済みユーザー
- **I want to** 選択したチャンネルにメッセージを送信したい
- **So that** 他のユーザーとリアルタイムでコミュニケーションできる
- **Priority:** Must
- **Acceptance Criteria:**
  - [ ] テキストを入力して Enter キーまたは送信ボタンで送信できる
  - [ ] 送信したメッセージが即座に画面に表示される
  - [ ] 別タブ・別ブラウザのユーザーにもリアルタイムで反映される
  - [ ] 送信者名と送信時刻が表示される
  - [ ] 新しいメッセージが来ると自動スクロールする

---

## US-005: 画像送信
- **As a** ログイン済みユーザー
- **I want to** チャットに画像を添付して送信したい
- **So that** テキスト以外の情報も共有できる
- **Priority:** Should
- **Acceptance Criteria:**
  - [ ] 画像ファイルを選択してアップロードできる
  - [ ] アップロード後、画像がメッセージとして表示される
  - [ ] 画像は Supabase Storage に保存される
